Things I’ve built and shipped

2022 to 2025

A superconducting detector for metal contamination

A 24-channel SQUID system built with Toyohashi University of Technology. I wrote the data acquisition software, the real-time CIC and FIR filtering, the serial protocol that tunes the sensors, and the routine that auto-biases eight Josephson junctions. Detection accuracy rose 30%. The first model debuted at Battery Japan 2023, and I’m credited as a co-author of the machine, announced at EASSE in Taiwan in 2025.

Publication:

ResearchGate

C++, MFC, PCIe DAQ, RS-232, SQL Server

2026, ongoing

Edge AI for a food-inspection metal detector

A classification layer on the STM32N6 that sits on top of the working detector, without touching its signal chain or front-end hardware. I run the pipeline from dataset evaluation through training to deployment, and tell the data-labeling team which signals teach the model best.

PyTorch, TensorFlow, Edge Impulse, STM32Cube.AI

2023 to 2026

FDA-ready control software for pharmaceutical machines

The 21 CFR Part 11 system that let the NT-Series machines be sold to pharmaceutical companies. One unified HMI, recipes and batch data in SQL Server, LDAP sign-in, and real-time PLC and PC communication. I was the only system developer on a team of three.

C#, .NET 8, WPF, OPC UA, EtherNet/IP

2022 to 2023

An eight-channel signal processor, start to finish

The dedicated signal CPU for a new metal detector: CIC and FIR filters, noise averaging, SPI to the analog front end and two-way CAN bus control with the main CPU. I owned the whole signal-processing side.

C, dsPIC33CH, SPI, CAN
